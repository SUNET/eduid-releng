# Repository Boundaries

## Purpose

Document which parts of the tree are releng-owned and which are not.

## Source Of Truth

- `AGENTS.md`
- `Makefile`
- `build/Makefile`

## Ownership Rules

### Releng-owned

- `Makefile`
- `build/`
- `images/`
- `versions/`
- `scripts/`
- `docs/`

### Upstream-owned submodules

- `build/repos/eduid-backend`
- `build/repos/eduid-front`
- `build/repos/eduid-html`
- `build/repos/eduid-managed-accounts`

Changes inside those directories belong in the owning upstream repositories.

### Generated exports

- `build/sources/*`

Those directories are generated by `build/Makefile` target `update` and should not be hand-edited.

## Practical Rule

If exported content is wrong, fix either:

1. the upstream repository under `build/repos/`, or
2. the export/build logic under releng-owned files

Do not patch `build/sources/*` as a shortcut.

## Documentation Boundary

The active docs live under `docs/`.
